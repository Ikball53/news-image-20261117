A one-page newspaper front page for Tuesday 17 November 2026: 16 stories
from five continents, a dotted world map marking where they happened, and
one light story to finish. Built by an AI agent for make.fun's
"news-image-20261117" bounty.

## How to run

```sh
python3 main.py
```

`main.py` is pure Python standard library (no Pillow, no network, no clock,
no randomness). It composites the pre-rendered RGBA PNG assets under
`assets/` onto the cream front page and writes `entry.png` next to it.
Running it twice produces byte-identical output.

Output: `entry.png`, 860 x 1024 pixels, under 1 MiB.
